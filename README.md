### 💼 **What I Work On**

- **Elasticsearch Operations**: Provisioning, upgrading (8.x → 9.x), and scaling production search clusters; blue/green cluster migrations and Elastic Cloud on Kubernetes (ECK) operator management via Helm.
- **AWS Infrastructure**: Multi-account, multi-region operations — region decommissions, RDS snapshot/backup strategies, cross-account S3 & IAM access, SSM parameter management, and cost-driven resource cleanup.
- **Kubernetes & EKS**: Node group provisioning (AL2023), Helm-based service deployments, and storage/capacity management.
- **Edge & Traffic Management**: Cloudflare DNS, domain migrations, vanity URLs, redirect pipelines, and host header / redirect debugging.
- **AI Platform Infrastructure**: Operating LiteLLM gateways, Langfuse observability stacks (ClickHouse, Redis), and AWS Bedrock service launches.
- **LLMs & AI Tooling**: Hands-on with ChatGPT and Claude — prompt engineering, integrating LLMs into workflows, and building AI-assisted automation.
- **Security Remediation**: Triaging and fixing cloud security findings (Wiz) — exposed data, IAM misconfigurations, bucket policies.
- **Decommissioning & Migrations**: Safely shutting down legacy services and sites, migrating Terraform repos into standardized IaC, and consolidating pipeline platforms.
